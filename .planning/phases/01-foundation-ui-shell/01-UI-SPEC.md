- Upload button background
- Download button background

## Layout Contract

| Element | Position | Dimensions | Behavior |
|---------|----------|------------|----------|
| Controls bar | Top of viewport | Full-width, 16px internal padding | Horizontal layout, left-to-right flow |
| Canvas (Konva Stage) | Below controls bar | 500×500px fixed | Centered horizontally, 24px gap from controls |
| Upload button | Left of controls bar | Auto width, 12px×20px padding | First element in controls |
| Frame thumbnails | After upload button | 80×80px each | Two thumbnails side by side, 8px gap |
| Scale sliders | After frame thumbnails | 150px width each (approx) | Labeled "Photo Size" and "Frame Size" |
| Download button | Right of controls bar | Auto width, 12px×20px padding | Last element in controls |

**Page margins:** 32px (xl) on all sides.

**Desktop-only:** No mobile responsiveness. Minimum assumed viewport: 1024×768px.

## Component Specifications

### Upload Button
- **Style:** Background #FF6B35, white text, 8px border-radius, 12px×20px padding
- **Label:** "Upload Photo"
- **Typography:** 16px, weight 600
- **Hover:** Background #E55A28
- **Active state:** None (no persistent active state, action triggers file picker)

### Frame Thumbnails
- **Dimensions:** 80×80px each
- **Border:** 2px solid (default: #E5E7EB, active: #FF6B35)
- **Border-radius:** 4px
- **Layout:** Two thumbnails side by side, 8px gap between them
- **Label:** "Choose Frame" text above thumbnails
- **Default state:** Neither selected (or first selected by default)
- **Active state:** 2px solid #FF6B35 border

### Scale Sliders
- **Type:** HTML `<input type="range">`
- **Styling:** `accent-color: #FF6B35`
- **Labels:** "Photo Size" and "Frame Size" (14px, #1F2937, weight 400)
- **Layout:** Vertical label above slider
- **Width:** Approximately 150px each (flexible to fit controls bar)

### Download Button
- **Style:** Identical to Upload button
- **Label:** "Download"
- **Typography:** 16px, weight 600
- **Hover:** Background #E55A28
- **Enabled state:** Only when photo is uploaded and composited

### Canvas Empty State
- **Dimensions:** 500×500px
- **Fill:** #F5F5F5
- **Message:** "Upload a photo to get started"
- **Message style:** 14px, #9CA3AF, weight 400, centered vertically and horizontally
- **Behavior:** Disappears once user uploads a photo

## Interaction Contract

### Upload Flow
1. User clicks "Upload Photo" button
2. Browser file picker opens (accept: image/*)
3. Selected image loads into Konva Stage as draggable layer
4. Canvas empty state disappears
5. Scale sliders become active
6. Download button becomes enabled

### Frame Selection Flow
1. User clicks one of two frame thumbnails
2. Clicked thumbnail border changes to #FF6B35 (2px solid)
3. Previously selected thumbnail border returns to #E5E7EB
4. Selected frame PNG overlay loads on top of photo layer in Konva Stage
5. Frame is draggable/scalable via "Frame Size" slider

### Scaling Flow
1. User drags "Photo Size" slider
2. Photo layer scales in real-time (Konva transform)
3. User drags "Frame Size" slider
4. Frame layer scales in real-time (Konva transform)

### Download Flow
1. User clicks "Download" button
2. Konva Stage exports to PNG via `.toDataURL()`
3. Browser triggers download of composited image (filename: `profile-frame-${timestamp}.png`)
4. No confirmation modal, immediate download
